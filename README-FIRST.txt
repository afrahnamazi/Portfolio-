Afrah Namazi Portfolio — GitHub Pages

1. Extract this ZIP.
2. Upload the contents so index.html is at the repository root.
3. Keep the assets folder and its subfolders together; dashboard images are in assets/dashboards.
4. The included 404.html supports direct project links on GitHub Pages.
5. Enable GitHub Pages for the main branch and repository root.

When updating an existing repository, replace its old files with all files from this ZIP.
